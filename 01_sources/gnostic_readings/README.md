# Gnostic体系参考资料

主要依据：Waldstein/Wisse1995四抄本Synopsis；Turner2001的Sethian体系整理；Robinson1988原典英译；Irenaeus、Hippolytus所传Valentinian及其他体系；Pistis Sophia的Mead1921英译。各文本独立，不能合并为唯一教义。

下载位于downloads目录，原地址与SHA-256在download_manifest.json。完整现代英译和书籍只作本机参考，不纳入Git。下载不等于全部精读；逐条使用的关系见图谱数据及原典定位。gnosis.org请求失败的条目保留失败记录；成功镜像另记，不伪装下载成功。

核验中排除了两个错配：某检索结果链接实际为Salut gnostique et métaphysique plotinienne，而非Turner2001；Greek Gospel of the Egyptians与Coptic Holy Book of the Great Invisible Spirit不是同一作品。真实Turner扫描版与Coptic文本已经另行取得。VE镜像残留Zostrianos小标题，但正文确为A Valentinian Exposition，依正文及另一版本校核。

工作方式：现成学术整理搭结构，可检索原典核关键关系和分歧；不再逐页翻PDF。图谱不是全文译本，名号、功能与关系用简明中文解释，术语保留英文。
