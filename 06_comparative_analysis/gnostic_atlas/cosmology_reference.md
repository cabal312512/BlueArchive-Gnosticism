# Gnostic体系与名号总表

2026-10-31。以Sethian / Apocryphon of John为主视图、Ptolemaic Valentinian为主对照；其余传统和变体分开。角色、属性、领域、群体与过程分别标识。层号仅为图面排布，不是跨文本统一官阶。完整数据见atlas_data.json，可视化见index.html。

## Apocryphon of John

主视图 · long recension · NHC II / IV

- 本源与显现：不可言说的Invisible Spirit通过其Thought显现；Barbelo及神圣属性构成上界展开。
- 上界秩序：Autogenes与Four Luminaries组织神圣领域；Adamas、Seth及其seed分别有归属。
- 失衡与世界：Sophia独自生育Yaldabaoth；后者生成下层权能、模仿上界组织世界。
- 人的构成：Archons造人的身体；母之力量进入Adam，人的认知超过造物者，引发压制。
- 救赎与归返：Luminous Epinoia帮助认识来源；Spirit与Counterfeit Spirit构成不同方向；长本末尾Pronoia以Five Seals唤醒。

## Valentinian · Ptolemaic

主对照 · Irenaeus I.1–8

- Pleroma展开：Bythos–Sige、Nous–Aletheia、Logos–Zoe、Anthropos–Ecclesia构成Ogdoad；再出Decad与Duodecad，共三十。
- 失衡与分界：Sophia追求认识Father而失衡；Horos使其恢复，排出其Enthymesis／passion。
- 下界形成：外在Achamoth经Christ与Soter的不同帮助而形成；产生psychic Demiurge及神性seed。
- 人的构成：material、psychic、pneumatic是不同构成／类型；神性seed并不等同一位三十名单中的Aeon。
- 最终归返：Achamoth与Soter结合，pneumatic seed进入Pleroma，psychic得中间安息，matter被消除。

## 术语

- **Monad**：最高一者的称法；在不同文本不必都作为原生专名出现。不是某位普通Aeon的官衔。
- **Pleroma**：神圣fullness／整体及其领域。可以包含内部生成差别，不等于一排所有成员完全同级。
- **Aeon / Aeons**：可指神圣存在、其领域、时代或宇宙区域；须按文本及位置判断。不存在全Gnosticism统一总数。
- **Emanation**：来源的展开；不同文本用生育、Thought、Light、Word等方式叙述，不一律是物理生殖。
- **Syzygy**：相应的配对；可为male／female等关系，不应不加解释直接当现代婚姻。
- **Demiurge**：制造／组织世界的角色名称；与Yaldabaoth常重合但不跨传统自动同一。
- **Archon / Archons**：统治者及其powers；既可为首领，也可指下属群体，数量与名单各版本不同。
- **Ogdoad / Decad / Duodecad**：八／十／十二的组列。可数存在也可指领域；不同文本不可只凭数字对齐。
- **Pronoia / Protennoia / Ennoia**：Providence、First Thought、Thought等相关表达；在特定文本可连到Barbelo，不全局强制同一。
- **Epinoia**：insight／reflective thought；Luminous Epinoia是AJ帮助者。与Sophia、Life等有交叠但须分文本。
- **Pneuma / Psyche / Hyle**：spirit／soul／matter；对应pneumatic／psychic／hylic并非所有文本都同样分人。
- **Gnosis**：使人认识神圣来源及自身处境的knowledge；与revealer、仪式、生活和归返相连。
- **Divine Spark**：本项目比较用的概括术语：个体中的神性来源／成分。不是各原典统一采用的专名，也不推出每个人就是某位Aeon。
- **Heimarmene**：宇宙命运与限制机制；不必每篇都同一拟人化对象。
- **Five Seals**：部分Sethian文本的baptism／启示救赎语言；不能自动套给任何出现五的设定。
- **Kenoma / Hysterema**：缺乏、空缺及Pleroma外不足状态的相关词；不把它们当作各篇都用的统一地图标签。

## 版本差异

- **AJ · long / short**（II / IV与III / BG）：共有神圣生成、Sophia、下层造物、人类与启示骨架；措辞、权能名单、身体名录和末尾Pronoia段存在差异。
- **AJ · Barbelo Pentad**（Truth / Ennoia）：长本明确Truth，短本相关配列采用Ennoia／Thought语言；不能复制一张表后声称逐字相同。
- **AJ · Luminaries**（Harmozel / Armozel; Oroiael / Oriel; Daveithe / Daveithai）：异拼不自动表示不同神；不同传述如Irenaeus I.29还改变配列和名称。
- **Aeons数量**（AJ四组三项；Valentinian 8＋10＋12；EUG六对及72／360；PS宇宙区域）：不同层的局部数字，不能化约为只有十二个Aeons。
- **Sophia位置**（AJ / Valentinian / EUG / PS）：可为失衡者、Pleroma内Aeon与外在Achamoth的相关来源、多个配偶称号、或第十三Aeon的受困者。
- **Christ / Autogenes**（AJ 与 Irenaeus I.29）：AJ紧密相连；I.29按先后叙述区分，不应跨版本自动合并。
- **Demiurge评价**（AJ / Flora / TT）：敌对与无知、公正的中间者、被Logos用来组织下界，是不同材料给出的不同功能组合。
- **Sabaoth**（AJ名单 / HA / OW）：名字可在不同下层清单出现；HA与OW明确写悔悟与提升，不能被永久邪恶的统一定义覆盖。
- **Samael**（AJ 与 Irenaeus I.30）：AJ列为Chief Archon别名；I.30还把它用于serpent名号，必须区分来源。
- **Basilides报告**（Irenaeus I.24 / Hippolytus VII）：365天与顺次powers的结构，对照non-existent God、seed、三Sonship与两大Archons；不将两报告合成一套。
- **同属Pleroma**（共同神圣来源 ≠ 完全同一内部层级）：容纳Sophia、其他神圣存在与群体，不要求每个群体占一位专名Aeon的名额。
- **AJ · short七天名单**（III / BG 对照 II）：III首位Aoth、BG首位Yaoth为lion-faced；II首位Athoth为sheep-faced。第五项短本Adonaios，长本Sabaoth；逐本保存。
- **AJ · 文本保存状况**（II / III / IV / BG）：II为较完整长本，IV为有缺损的长本；III与BG为两个短本见证，仍有独立异文。长短本是recensions，不是四个现代译者。
- **神性来源与个体**（Divine Spark / Seed / Aeon）：神性由上界而来、参与神圣群体、对应某个专名Aeon，是三个不同关系。本文分别记录，不替用户提出人人都是某位Aeon的说法。
- **AJ · Wisdom / Sophia**（II 8,18–20 与9,25起）：按原文词形及标准学术解释合为同一位，保留Wisdom别名；不重复计为两个Aeons。
- **AJ · 十二与七的关系**（II 10,26–12,25）：保留Authorities、七天的配置、兽面名列及powers展开。不能把图上同排等同于已证同一群体，也不画成一套无争议的低一级人口。
