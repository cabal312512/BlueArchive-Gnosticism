# 当前理论与保留问题

这里只记作者目前采用的模型和讨论边界，不记录普通编辑、排版、校对或上传。作者的当前中文论文是具体论述的依据；下面的“采用”是工作模型，不表示官方确认或已经完成证明。AI独立评价不自动撤销作者观点，也不能替作者新增裁决。

## 当前采用

| 对象 | 作者采用的对应与范围 |
| --- | --- |
| 联邦学生会长 | Sophia，是作者核心对应。失误、悔悟、最年轻、退隐与补救是主要线索。 |
| 老师 | Luminous Epinoia，作者倾向大概率成立；比较帮助者功能，游戏可以改写救赎方向与生活主题。原典中由上界派遣，不写成Sophia直接召来。 |
| 无名众神相关体系 | 整体关联Yaldabaoth；不要求单个对象独占原型全部特点。 |
| 无名祭司 | Archons，也可承接Yaldabaoth的部分功能及性格特点。 |
| 柔和的声音 | 作者判断为无名众神本体，论文以此讨论；原文未明示身份的事实另存，不把工作前提当直接剧情证据。 |
| 被遗忘诸神与学生 | 学生可理解为被遗忘诸神在现世的个体化显现，模型中归于Pleroma侧。祭司称呼、Kyrie标题、遗忘条件及三件遗物的会长关联是主要线索。 |
| 学生光环 | Divine Spark的外在表征；不要求每名学生有独立神话原型。 |
| 名字、遗忘与身份 | 围绕个体在现世如何确立自我、展开生活讨论，不让来源或使命独占生活价值。 |

无名众神本体也可放在Pleroma侧是保留分支，只指与爱丽丝对话的本体，不把整个旧神体系都归到上界。不固定其高于Sophia，不把无名众神与被遗忘诸神强塞成两位指定Aeons。人有神性火花、可溯源上界，不等于每个人原本就是某位Aeon。

## 必须保留的区别

- 神本体可以宽厚超然，祭司努力崇拜、按有限理解执行并形成僵硬使命；不擅自改写成祭司曲解神的全部意思，也不是为祭司免责。原型的不同特点可由不同对象承接。
- 原典事实、剧情事实、作者对应与AI判断分别说明；“可以解释”“可能取材”“官方确认”不能混写。游戏可能只是参考大致结构，不必逐项照搬。
- Tripartite Tractate的合一属于原典的正面救赎，不是原典Archons阴谋；游戏中的重置计划与之作结构／改写比较。
- 学生普通少女生活、个体选择、过程价值与日常奇迹是重要主题；不擅自把作者尚未说清的高维体验写成哲学定论。
- 学生神话原型讨论保留，不能升级成全员完整映射。Gnosticism结尾评价以当前作者稿为准；作者已把绝对性措辞改为“一般认为”“更像”。

## 明确排除或不主动展开

- 伪会长不对应Yaldabaoth；不把不知火花耶的性格行为移给联邦学生会长。
- 不把伊甸条约夸大为Sophia创世失误，不强比大人卡片的生命消耗与Epinoia劳苦，不因开局失忆就认定对应某次神圣降临。
- 配偶并非已确立强证据，不编造会长自述单身。工坊／Craft Chamber的早期比附不自动恢复为当前主论证。
- 当前7.2用祭司宣告及本船兵器线索论两类诸神的敌对，并比较Sophia、Zoe、Sabaoth相关冲突；早期暂不采用战争比较的限制不覆盖作者现稿。能使用两种神力仍不足以证明两类神同源。
- 人工遗物／化石燃料问题保留，不主动继续展开。遗忘是否自愿、Aeon逐个名号分配都不是讨论重点。
- 不把三姐妹无光环直接判成没有任何神性火花；Kabbalah、神秘／恐怖／崇高与Gnostic的关系按具体证据处理，不强行归一。

## 未决问题

1. Sanctum Tower的来源：黑服追溯到无名神技术，祭司列为被遗忘诸神产物。色彩导致反转不解决来源矛盾；管理或使用遗物不等于亲手制造。
2. 会长失误与旧世界／无名众神的时间因果；Sophia为Yaldabaoth之母及神力被夺在游戏中如何对应。
3. 本体／祭司分担、Pleroma分支及全体学生范围的证据强度，可继续讨论，不把相容解释当独立证明。
4. 作者在7.3区分“维度高低”与“抽象程度”，用于解释游戏同级敌对势力与Pleroma／Yaldabaoth关系的差异；这属于作者提出的模型区分。另以“如果此前推断可靠”为前提，猜想会长最初激活了祭司等，不能改成已知剧情。
