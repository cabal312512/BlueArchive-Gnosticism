# 宗教与神话短文核查

2026-11-02，第60轮。正文见[中文短文](../rationale/why_gnosticism.md)，另有同目录英、日、韩版。本轮只改本地。

用户先要求所有点尽量保留，随后允许删除不合适项，最后明确：能纠正的就纠正，学生神话原型不要删。最终保留四组主题与学生原型讨论，删去夸饰、无法成立的确定性断言和不能简单纠正的具体对应。主助手直接查语料、词典、宗教原文及可靠说明并写作，未调用DeepSeek。

## 逐项判断

| 原稿说法 | 核查与处理 |
| --- | --- |
| 第一行代码起就是宗教废墟上的巴别塔；官方完全明牌 | 无法核实的修辞，删除。改为游戏反复借用宗教、神话与神秘学，部分借用进入叙事结构。 |
| Kivotos是诺亚方舟与约柜的专属译词 | 保留词源，删除“专属”。LSJ还列出普通箱、柜、钱柜等用法，圣经的方舟与约柜是其具体用例。 |
| Shittim是制造约柜的唯一神圣防腐木材 | 保留皂荚木及Exodus 25出处。删除“唯一神圣防腐”：原文给出材料要求，也用同种木材做抬杠；不能由此推出这种木材具有排他的神圣地位。 |
| Shaked之杖是圣柜中的顶级智能核心 | 游戏确有曾保存在圣柜内的说法，但形态为智能手表。没有把它定性成“智能核心”；删去“顶级”。Shaked的杏树含义及Aaron's Rod联想保留。 |
| Numbers 17说亚伦之杖存放在约柜内 | 必须分开引文。Numbers 17:8写芽、花与杏子，17:10要求放回“法版前”；Hebrews 9:4才列为约柜内物品。短文同时列两处，避免把后者塞给前者。 |
| Perez-Uzzah是辅助运算机制、圣所地名 | 游戏写process，保留“进程名”，不添加机制细节。2 Samuel 6:6–8记乌撒触柜死亡和当地命名；不是据此确认的独立圣所名。 |
| 两座救赎方舟直接等同史诗中的神圣方舟 | 保留Utnapishtim与Atra-Hasis的洪水故事人名来源，不把游戏两船的作用写成一致，也不把史诗原船定为游戏设定。 |
| Sanctum Tower直接取自Sanctum Sanctorum | Sanctum自身即有圣所含义，只保留词义；未找到确定它缩写自该完整短语的依据。 |
| 阿里乌斯地下圣所的人工天使完全取自启示录 | “默示录天使”与吹号天使的联系确有剧情说明；保留该点。删除将所有人工天使合为同一明确来源的写法。此处证据含第一部第6篇，不能写成仅有早期伊甸条约篇的内容。 |
| Communio Sanctorum只是贾斯提纳的亡灵傀儡军团 | 游戏把它用于更广泛的圣徒体系，黑服和巨匠都使用该术语。改为“圣徒系统”；保留Apostles' Creed的“圣徒相通”来源，不把亡灵复制与信经教义本身等同。 |
| Trinity与Arius完整重演325年清洗史 | 学园名、公会议及分裂压迫的结构对应保留；改为“改写”。现实中的Arian争论及政治兴衰并未在325年一次结束，不写“彻底驱逐”或“完整重演”。 |
| Vanitas…是旧约的拉丁原文、贯穿主线全篇 | 原始语言不是拉丁语，改为Ecclesiastes 1:2的拉丁译文。语料确有重复使用，删去“主线全篇”。 |
| Kyrie是各章副标题、泛称大公教会核心仪式 | 保留伊甸条约篇中使用该祷文。Kyrie eleison是希腊语祈求，不把所有章节副题概括成同一短语。 |
| Gematria专属于Kabbalah | 保留希伯来字母数值释义的含义。该方法也见于更广泛的犹太释经，不称独占方法。 |
| Decagrammaton融合四字神名与十诫 | “神名十文字”有剧情明文，命名形式可比较Tetragrammaton；“与十诫融合”未获证实，删除。 |
| Binah是第一预言者 | 明确错误：Binah第三，Kether第一。短文纠正为第三，保留十个Sephirot、Tree of Life与Path的剧情联系。 |
| Ain、Soph、Aur各自依次意为无、无限、无限光 | 误把累积短语拆成单词释义。三人名字连成Ain Soph Aur；三帷幕是Ain / Ain Soph / Ain Soph Aur，并非Ain / Soph / Aur各自的直译。保留命名联系，指明西方Hermetic Qabalah的具体表述，避免拿一个版本代表所有Kabbalah。 |
| 色彩使Mystic反转为Terror，直接等同Qliphoth | Mystic反转为Terror是剧情事实；“直接对应Qliphoth”未找到文本依据，且生命之树被污染成一张逆树不是所有Kabbalah版本的统一机制。这项不能简单当事实纠正，短文删除，未改既有论文立场。 |
| Abydos全员完整映射九柱神 | 保留学生原型。白子—Anubis、星野—Horus有剧情明说；Bastet、Hathor、Thoth保留为比较对象，不冒充逐人确认。原列并非Heliopolitan Ennead的标准成员表，不再统称九柱神。 |
| Gehenna全员对应Goetia七十二魔神 | 保留地名与恶魔学意象，以及Belial、Astaroth、Beelzebub的原型讨论；不作全员宣称。标准Goetia列Belial、Astaroth，不列Beelzebub；改用涵盖Goetia及更广恶魔传统的说法。 |
| Trinity高层完整映射四大天使品阶及Azrael | 天使名不是四个“品阶”，原稿也没有逐人证据。保留天使与殉道者原型讨论及Michael、Gabriel例子，删去完整映射、固定四大品阶和本轮无锚点的Azrael。 |
| 百鬼夜行全套收纳八百万神，明确含Amaterasu、Susanoo | 保留日本神怪、神社与阴阳术主题。不把未经核定的具体神名加入短文。数据库关键词未命中本身不等于证明不存在，因此只说明本轮没有给出足够证据。 |
| 山海经、四象、道教炼丹术是同一原典的完整神系 | 保留中国神兽与炼丹元素，用游戏确有的玄武商会、玄龙门、炼丹术研究会举例。不把玄龙门直接改名成青龙，也不把未找到剧情锚点的朱雀写成确认事实。 |

## 关键剧情原话

以下定位用现有日文快照的篇／章／话。括号内台词编号仅用于本核查记录，短文没有数据库索引。

### Shaked之杖的存放位置与形态

第2部序章，第1章第3话，花耶向老师说明自己如何调查此物。她将其价值视为推测，后面还承认无法确定会长记录是否有误，因此不把她的“能力”介绍直接改成客观设定。

> **カヤ**：そしてついに、「シッテムの箱」に準ずるオーパーツが、#nシャーレの地下室にある[ruby=せいひつ]聖櫃[/ruby]の中に保管されていることを突き止めたのです。
>
> **花耶**：最后，我终于查明，与“什亭之箱”相当的人工遗物，被保管在夏莱地下室的圣柜里。
>
> **カヤ**：その名は――「シャーケードの杖」。
>
> **花耶**：它的名字是——“Shaked之杖”。
>
> **カヤ**：……ですが実際の「シャーケードの杖」は、単なるスマートウォッチにしか見えませんでした。
>
> **花耶**：……但实际的“Shaked之杖”，看上去不过是一块智能手表。

### Perez-Uzzah是进程名

第1部第1篇第3章第39话，普拉娜解除什亭之箱限制时使用此名；本轮只据此称进程，不追加运算模块的技术设定。

### 公会议与Arius：有结构对应，非完整史实重演

伊甸条约篇第2章第1话，圣园未花向老师介绍Trinity的历史：先讲互相争斗的派别联合，再讲反对联合的Arius遭到压迫。

> **ミカ**：私たちはもう戦わなくて良い、一つの学園になろう……そんな話をしたのが、いわゆる「第一回公会議」。
>
> **未花**：我们不必再战斗了，合成一所学园吧……讨论这些事情的，就是所谓的“第一次公会议”。
>
> **ミカ**：元々は私たちとあんまり変わらなかったはずの、一つの分派。
>
> **未花**：那原本也是一个分派，应该和我们没有太大区别。
>
> **ミカ**：経典に関するちょっとした解釈の違いがあったくらいで、結構色んなところが似てたんだって。
>
> **未花**：据说只是对经典的解释有一点不同，其他很多地方都很相似。
>
> **ミカ**：でも、そのアリウスは連合を作ることに猛烈に反対して……最終的には、争いに繋がっちゃったの。
>
> **未花**：但Arius激烈反对组成联合……最终就演变成了争斗。
>
> **ミカ**：連合になって強大な力を持つようになったトリニティ総合学園は、その大きな力でアリウスを徹底的に弾圧し始めた。
>
> **未花**：组成联合、拥有强大力量的Trinity综合学园，开始用这股力量彻底打压Arius。

> **日鞠**：这棵“生命之树”上，一共有十个被称为“Sephirah”的东西。

## 宗教文本核查要点

- [LSJ：κιβωτός](https://atlas.perseus.tufts.edu/dictionaries/entry/urn%3Acite2%3Ascaife-viewer%3Adictionaries.v1%3Alsj-n57321/)同时列普通箱柜与Genesis 6:14、Exodus 25:10用例，故“专属”不成立。
- [Numbers 17:8–10](https://www.biblegateway.com/passage/?search=Numbers+17&version=KJV)与[Hebrews 9:4](https://www.biblegateway.com/passage/?search=Hebrews+9&version=KJV)分开读；不混同各处对杖的存放描述。
- [Ecclesiastes 1:2，Nova Vulgata](https://www.vatican.va/archive/bible/nova_vulgata/documents/nova-vulgata_vt_ecclesiastes_lt.html)确有“vanitas vanitatum et omnia vanitas”，这是一种拉丁译文。
- [The Kabbalah Unveiled，Introduction §38](https://original.sacred-texts.com/jud/tku/tku03.htm)逐层列出Ain、Ain Soph、Ain Soph Aur。这是西方神秘学作者的具体编排，不能当作所有犹太Kabbalah的统一名目，也不能把Soph单独译成“无限”。
- [Goetia名录](https://sacred-texts.com/grim/lks/lks05.htm)列Astaroth为第29灵、Belial为第68灵；Beelzebub不在这份七十二灵表内。因此短文用更广泛的恶魔学范围。
- [First Council of Nicaea](https://www.newadvent.org/cathen/11044a.htm)与[Arius放逐及召回研究](https://academic.oup.com/jts/article-abstract/60/1/109/1684824)支持区分325年的谴责和后来持续的政治争论；短文没有把两段历史逐事等同。

更多网页出处随四语短文保留。上述是支持“为什么沿宗教神话去读游戏”的背景材料，不给既有论文擅自增加新的角色对应结论。
