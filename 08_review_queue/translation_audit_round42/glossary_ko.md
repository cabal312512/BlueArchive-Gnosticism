## 1. Gnosticism

中文第8行；译文修改前第8行，修改后第7行。

删除哲学运动、本质关联、最深关联等额外定性；保持相关，不强化成必然通向救赎。

**中文依据**

**Gnosticism**：对一组古代宗教思想与传统的统称。与本文最相关的观念是：现实世界的创造者之上还有更高的神圣来源，人内在也保有来自那里的神圣成分，认识自己的来源与摆脱束缚、获得救赎有关。

**修改前**

```markdown
**Gnosticism**: 고대의 일련의 종교 사상과 전통을 아우르는 총칭. 본고와 가장 깊이 연관된 관념은 "현실 세계의 창조주 위에 더 높은 신성한 근원이 존재하며, 인간의 내면에도 그곳에서 유래한 신성한 요소가 깃들어 있어, 자신의 근원을 자각하는 것이 속박에서의 해방과 구원으로 이어진다"는 점이다.
```

**修改后**

```markdown
**Gnosticism**: 고대의 종교 사상과 전통의 한 무리를 아우르는 총칭. 이 글과 가장 관련 있는 관념은 현실 세계의 창조자 위에 더 높은 신성한 근원이 있고, 사람의 내면에도 그곳에서 온 신성한 요소가 남아 있으며, 자신의 근원을 아는 것이 속박에서 벗어나 구원을 얻는 일과 관련된다는 것이다.
```

## 2. Father

中文第16行；译文修改前第16行，修改后第15行。

英文补回字面父，不扩成至高本体论、超越性神圣原则；韩文不添加维度。

**中文依据**

**Father**：意为“父”。在相关文本谈论最高来源时，是对至高神圣者的称呼。

**修改前**

```markdown
**Father**: '아버지'를 뜻함. 관련 문헌에서 최고차원의 근원을 논할 때 지고한 신성한 존재를 일컫는 호칭이다.
```

**修改后**

```markdown
**Father**: ‘아버지’를 뜻한다. 관련 문헌에서 최고의 근원을 말할 때 지고한 신성한 존재를 부르는 호칭이다.
```

## 3. Pleroma

中文第18行；译文修改前第18行，修改后第17行。

恢复可以先理解为，不写成固定定义；不增超越性与终极。

**中文依据**

**Pleroma**：本义是“圆满”或“充盈”。可以先理解为神圣存在及其完整生命所构成的整体；论文用它说明更高的神圣来源与归返方向。

**修改前**

```markdown
**Pleroma**: 본래 의미는 '원만' 또는 '충만'. 신성한 존재들과 그들의 온전한 생명으로 이루어진 총체적 영역으로 이해할 수 있다. 논문에서는 더 높은 신성한 근원 및 회귀의 방향성을 설명하는 데 쓰인다.
```

**修改后**

```markdown
**Pleroma**: 본래 의미는 ‘충만함’ 또는 ‘가득 참’. 우선 신성한 존재들과 그 온전한 생명이 이루는 전체로 이해할 수 있다. 논문에서는 더 높은 신성한 근원과 돌아갈 방향을 설명하는 데 사용한다.
```

## 4. Aeon / Aeons

中文第20行；译文修改前第20行，修改后第19行。

恢复常指、也可以涉及的范围；不增加本体论领域等规定。

**中文依据**

**Aeon / Aeons**：单数与复数。在相关神话中，常指从神圣源头展开的永恒存在，也可以涉及它们所在的领域。它们的数目与关系随文本而变。

**修改前**

```markdown
**Aeon / Aeons**: 단수형과 복수형. 관련 신화에서 신성한 근원으로부터 유출된 영원한 존재들을 가리키며, 그들이 거하는 영역을 뜻하기도 한다. 그 수효와 상호 관계는 문헌마다 다르다.
```

**修改后**

```markdown
**Aeon / Aeons**: 단수형과 복수형. 관련 신화에서 흔히 신성한 근원으로부터 펼쳐지는 영원한 존재들을 가리키며, 그들이 있는 영역과 관련되기도 한다. 수와 관계는 문헌에 따라 달라진다.
```

## 5. Sophia

中文第22行；译文修改前第22行，修改后第21行。

删除深深悔悟、主动宇宙修复、未与配偶等本条中文没有的补充；书名统一英文。

**中文依据**

**Sophia**：名字意为“智慧”。Apocryphon of John讲她单独行动、生出有缺陷的后代，随后悔悟，参与补救。论文以此比较联邦学生会长。

**修改前**

```markdown
**Sophia**: 이름의 뜻은 '지혜'. 『요한의 비밀 가르침』(Apocryphon of John)에서 그녀는 단독으로 행동하여 결함 있는 후대를 낳은 뒤, 깊이 뉘우치며 사태의 수습에 참여한다. 논문에서는 이를 총학생회장과 비교한다.
```

**修改后**

```markdown
**Sophia**: 이름은 ‘지혜’를 뜻한다. Apocryphon of John은 그녀가 홀로 행동하여 결함 있는 자식을 낳은 뒤 뉘우치고 수습에 참여하는 이야기를 전한다. 논문은 이를 총학생회장과 비교한다.
```

```markdown

```

**修改后**

```markdown
**The Ninth**: Apocryphon of John에서 Sophia가 뉘우친 뒤 잠시 머무는 곳으로, 자신이 낳은 자식 위에 있다. 논문은 그녀가 무대 뒤로 물러나는 모습을 논할 때 이 명칭을 사용한다.
```

## 14. Psychic / Pneumatic

中文第46行；译文修改前第46行，修改后第45行。

恢复部分Valentinian材料；不增加本体论属性，不将概括名称改成实体本身。

**中文依据**

**Psychic / Pneumatic**：分别是与Psyche、Pneuma有关的形容词，常译为“属魂的／属灵的”。在部分Valentinian材料中，它们还用于划分人的类型。Pneumatic是属性或类型用语；Divine Spark是内在神性成分的概括名称。[人的内在及相关区分](https://iep.utm.edu/gnostic/)

**修改前**

```markdown
**Psychic / Pneumatic**: 각각 Psyche, Pneuma와 관련된 형용사로, 흔히 '혼적인 / 영적인'으로 번역된다. 일부 발렌티누스파(Valentinian) 문헌에서는 인간의 유형을 나누는 데 쓰이기도 한다. Pneumatic이 속성이나 유형을 나타내는 용어라면, Divine Spark는 내재적 신성 요소 자체를 총칭하는 표현이다. [인간의 내면 및 관련 구분](https://iep.utm.edu/gnostic/)
```

**修改后**

```markdown
**Psychic / Pneumatic**: 각각 Psyche와 Pneuma에 관련된 형용사로, 흔히 ‘혼에 속한 / 영에 속한’으로 번역된다. 일부 Valentinian 자료에서는 사람의 유형을 나누는 데도 쓰인다. Pneumatic은 속성이나 유형을 나타내는 말이고, Divine Spark는 내면의 신성한 요소를 아우르는 이름이다. [인간의 내면과 관련 구분](https://iep.utm.edu/gnostic/)
```
