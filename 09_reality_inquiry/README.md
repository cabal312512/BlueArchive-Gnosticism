## 文档管理

按专题整理，不按轮次不断新建文件。每篇保留当前观点、有用原话和必要判断；只有表述确实需要帮助时才另写转述。要求和分工集中在研究约定。

新整理与助手判断交作者核对，确认后更新当前表述。修改不影响完整对话备份；旧稿有保留价值时放archive/，不让旧助手意见混入当前理论。

判断只处理会影响研究的问题，不把无关细节变成证明任务。具体标准见研究约定与根目录AGENTS.md中的判断铁律。
