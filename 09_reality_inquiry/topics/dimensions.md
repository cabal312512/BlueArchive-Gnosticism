# 维度、世界与灵体

依据第114轮作者说明整理。第112轮助手提出的“束缚程度与作用范围”定义未获采纳，现已撤下；历史表述仍保留在对话备份。本页转述供作者核对。

## 1. 维度的定义

> 其实这个比较好计量 就一个值 越大就越抽象越不好理解 越小就越物质越好理解 维度只有唯一的标准

**维度是描述存在或世界的抽象程度的单一数值。数值越高，越抽象、越难被人理解；数值越低，越物质化、越容易被人理解。**

所有世界与灵体使用同一个维度标准。此处“抽象”沿用作者对超出日常理解的存在层次的用词，不因此把灵体或Demiurge写成仅存在于思考中的抽象概念。

维度不再由束缚程度、作用范围或灵性多少共同定义。当前明确为单一尺度，本轮未设置具体刻度或给对象分配数值。

## 2. 世界与灵体

> 世界有多个 各个世界的维度有高有低 最低的暂定就是我们的现实世界（地狱之类的说法如果按之前的理论依旧是维度高于现实世界的） 最高的是Monad的级别

- 世界可以有多个，各自处在这个统一尺度的某个位置。
- 最低端暂定为当前现实物质世界；最高端为Monad的级别。
- 按作者此前理论解释的“地狱”等世界，也高于现实世界；这里的高低不是善恶或好坏排序。

> 但有灵体不一定就有世界  灵体可以在不同维度单独存在 世界是因为灵体的观察作用产生的（其实正常人也可以归入“灵体”）。

灵体可以独立存在于不同维度，不必每个灵体都带有一个世界。世界由灵体的观察作用产生；正常人也可归入灵体。不能把“一个灵体”“一个世界”“一个维度”当作一一对应。

## 3. 灵性总量与观察效果

> 那个个体灵性总量一般是不变的 不会随着维度高低变化 有变化的是观察的效果 可以理解成束缚更少时灵性能发挥的作用更大 而它本身是不会变强变弱的 当然应该有不少情况会让灵性总量变化 但那又是其他情况了。

同一个体的灵性总量一般保持不变；维度变化本身不会使这份灵性变多或变少。束缚减弱时，变化的是它能够发挥的作用与观察效果。

作者同时保留其他情况改变灵性总量的可能，本轮没有展开，不将“一般不变”改成绝对不变。

| 概念 | 本轮确定的含义 |
| --- | --- |
| 维度 | 存在或世界的抽象程度，采用统一的单一尺度 |
| 灵性总量 | 个体具有的灵性多少，一般不因维度变化而改变 |
| 观察效果 | 灵性在当前条件下实际发挥的作用，可以随束缚等条件变化 |
| 世界 | 由灵体的观察作用形成的环境，并不与每个灵体一一对应 |

## 4. 物质束缚的直接来源

> 把“受到多少束缚”放到定义里很不合适 因为这种束缚是稳定的维度最低的物质世界特有的效果 只是维度越低就越容易受物质世界的影响 受到束缚的直接原因是靠近或处在物质世界 不是因为维度低。

这里必须区分相关性与直接原因。维度较低使存在更容易受到物质世界影响；实际施加束缚的是稳定的物质世界，直接原因是靠近或处在其中。

当前因果表述：**靠近或处于稳定的物质世界 → 受到物质束缚 → 灵性能够发挥的作用受限。**

不再写成“维度低，所以维度本身压制灵性”。

## 5. 高维优势与物质载体

> 维度越高的对上维度越低的应该有不少优势 但不一定就能有那种“降维打击”的说法 因为这个物质世界作为一种载体反而会有一些好处

> 但如果维度差距很大比如对上Demiurge那就真的完全碾压了。

作者认为高维通常有优势，但不把任意维度差距都等同于绝对压制。物质世界作为载体也有有利条件，具体作用以后再展开；因此，不能仅按维度高一点就推断一定能击败低维存在。

差距很大时则另论。作者以人与Demiurge的差距为例，提出完全压制的判断。

## 对既有梦境解释的修正

睡眠中“权能放大”按作用发挥来理解，不写成灵性总量增加。需要说明的关系是意识与物质现实的联系变化、束缚减弱、原有灵性的作用发挥更充分；维度与这些变化有关，但维度本身不承担施加束缚的因果角色。
