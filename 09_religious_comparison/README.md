## 当前结论

“从本源而来，最终回归本源”确实是多种思想中反复出现的结构。Gospel of Truth与Mundaka Upanishad有直接表达；Plotinus以故乡比喻归返，《道德经》以归根和复命表达生成与返回。

对论文最有用的问题是：**神圣来源说明人从哪里来，但它是否也有权决定人在现世应该怎样活？** 这条讨论主线保留。比较材料用来说明这种问题有思想背景，不替作者追加新的游戏人物对应。
